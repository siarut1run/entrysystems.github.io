# Radius Team Entry サイト連携Bot
1. サイトの「Discord設定」で「接続設定」をダウンロードし、このBotと同じフォルダに `connection.env` の名前で置く。
2. Discord Developer PortalでBotを作成しServer Members Intentを有効化。botスコープでサーバーに導入する。ロール管理、チャンネル管理、閲覧、送信、埋め込み、履歴閲覧の権限を付与。
3. `connection.env` の DISCORD_TOKEN にトークンを記入。接続設定はサイトへのアクセス権を含むので他者に共有しない。
4. `py -m pip install -r requirements.txt`、`py bot.py`。
5. サイトで未認証・認証済み・承認チャンネル・登録パネルチャンネルのIDを保存。「登録パネルを送信」。
6. サイトで大会・チームを作り、準備完了後のコードをチーム代表へ共有。
7. 参加者はDiscordでコードと個人情報を入力。運営がサイトで承認し、Botがロール付与。

Botロールを未認証・認証済みより上に配置。運営承認チャンネルの@everyone・未認証・認証済みの閲覧を拒否する。チームカテゴリは専用チームロールのみ許可して作成。Administrator以外の運営にも閲覧させたい場合はカテゴリに運営ロールを手動追加。
既存メンバーへの未認証付与は手動。入室時の自動付与はBot起動中のみ動く。24時間運用にはVPS等が必要。以前のSQLite単独版Botとは保存先が異なるため、同時起動しない。
カテゴリ・ロール名の末尾の識別番号は、作成途中の障害や再試行で重複作成しないために使用する。
ランクはIRON 1〜IMMORTAL 3、RADIANT、UNRANKEDの英語形式。Tracker・最高ランクは自己申告で、運営の確認が必要。
サイト側に申請情報を永続保存。承認途中で失敗したら「Discord処理履歴」の再試行を押す。チーム合計は全承認者（補欠を含めて登録した場合は補欠も対象）。

Windowsでは接続設定を connection.env の名前で保存してください。connection.env.txt になっていないか確認。以前の .env も引き続き利用できます。


## v2 更新
Botを停止し、新しいZIPの bot.py に入れ替えて起動してください。接続設定 connection.env は引き継げます。
管理サイトの登録パネル設定で登録パネルを「送信・更新」してください。旧パネルには修正ボタンがありません。
メンバー変更・辞退は専用チャンネルIDを保存し、パネルを送信します。
チーム交代は旧選手が辞退申請、新選手が登録申請する流れです。ロール変更成功後に名簿とポイントへ反映します。
登録締切は日本時間。登録確定後は新規・修正・変更・辞退の申請を止めます。

## 最高ランクの選択
個人情報フォームの最高ランクはアイアン1〜レディアントの25択です。修正・再申請では現在のランクを選択済みにします。旧UNRANKEDは選び直してください。
更新時は `py -m pip install -r requirements.txt` を実行してください。

## 参加区分
最高ランクの下で「選手・コーチ・リザーブ」を選択します。区分は名簿・CSV・運営通知に保存します。区分によるポイント免除は設定していません。既存の未設定メンバーは選手として表示し、修正申請で変更できます。

## Discordのチーム名
大会内のチーム作成順に01から採番し、カテゴリ・ロール・テキスト・VCを `01_チーム名` に揃えます。末尾のID表記は除きます。既存チームは管理サイトのチーム詳細で「Discord名を更新」を押してください。チャンネルとロールのIDを使って名前を変更するため、履歴と権限は引き継がれます。

## 申請フォーム
X ID → Riot ID（名前#タグ）→ 表示名（配信記載）→ 最高ランク → 参加区分の順に入力します。Riot IDからTrackerへのリンクを生成します。表示名はDiscord名とは別に保存します。既存のTracker URLの登録も読み込めます。Botを最新版に差し替えて再起動してください。

## チーム削除・登録解除
管理サイトのチーム詳細でチーム削除、チーム内メンバー一覧または登録一覧で登録解除ができます。確認後にBotがDiscordのロール・チャンネル処理を行い、成功後に名簿と合計を更新します。登録確定中は確定解除が必要です。他の承認済み登録が残る場合はその登録のロールを維持します。削除失敗は再試行できます。チーム削除ではチャット履歴も消えます。

## 登録一覧のCSV
CSV発行は「ゲームID（Riot ID）,表記名（配信記載）,ランク」の3列だけを出力します。ランクの選択肢とCSVの表記はIRON 1〜RADIANTの英語表記です。
